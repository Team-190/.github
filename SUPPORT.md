# Support

Need help with a Team 190 repository?

- **Bugs and feature requests** — open an issue on the relevant repo using the appropriate issue template.
- **General questions** (build season, CAD/Onshape sync, robot code) — ask in the team's usual chat/Slack/Discord, or reach out to a programming/CAD mentor directly.
- **Security issues** — see [SECURITY.md](SECURITY.md); do not open a public issue for these.

This repository (`.github`) itself covers org-wide CI (BOM sync, GompeiLib sync) and shared defaults — for issues specific to those workflows, open an issue here.
