# Team 190

Welcome to the GitHub organization for **FRC Team 190**. This org hosts the software, CAD-integration tooling, and CI automation that support our robot code, scouting, and build-season workflows.

## What's here

- **Robot code** — season repos for our competition robots.
- **[GompeiLib](https://github.com/Team-190/GompeiLib)** — our shared robot code library, kept in sync across repos.
- **[.github](https://github.com/Team-190/.github)** (this repo) — org-wide defaults (community health files, issue/PR templates) and shared CI, including our Onshape-to-Baserow BOM sync automation.

## Contributing
