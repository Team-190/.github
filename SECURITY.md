# Security Policy

## Reporting a Vulnerability

If you discover a security issue in any Team 190 repository — including exposed credentials/secrets, a vulnerable dependency, or a CI/workflow misconfiguration that could leak secrets — please **do not open a public issue**.

Instead, report it privately by emailing **ecscher84@gmail.com** with:

- A description of the issue and where you found it (repo, file, workflow run).
- Steps to reproduce, if applicable.
- Any suggested fix, if you have one.

We'll acknowledge your report as soon as possible and follow up once the issue is resolved (e.g., secret rotated, dependency patched).

## Scope

This applies to all repositories under the Team 190 GitHub organization, including CI workflows and any credentials/secrets they use (Onshape, Baserow, GitHub tokens, etc.).
